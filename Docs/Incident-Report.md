# Incident Report

## Incident Summary

During Apache Benchmark testing with 50,000 requests, the application experienced temporary service degradation.

## Impact

Users observed:

* Failed API Requests
* Loading Screen Delays
* Request Timeouts

## Evidence

Application Error:

TypeError: Failed to fetch

Backend Error:

Request aborted

Alertmanager Alerts:

Multiple alerts triggered during peak traffic.

## Root Cause

High traffic generated by Apache Benchmark caused:

* Increased API load
* Increased network utilization
* Temporary request failures

## Resolution

Kubernetes automatically restarted unhealthy pods.

Prometheus confirmed service recovery.

Grafana dashboards showed resource normalization.

## Recovery Time

Estimated Recovery Time:

Less than 5 minutes

## Lessons Learned

* Monitoring stack detected issue successfully.
* Kubernetes self-healing worked as expected.
* Application remained recoverable without manual intervention.
