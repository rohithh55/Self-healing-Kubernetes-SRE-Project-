# Lessons Learned

## Key Findings

1. Kubernetes successfully recovered failed workloads.

2. Prometheus provided detailed metrics for troubleshooting.

3. Grafana dashboards clearly visualized system behavior.

4. Alertmanager detected service degradation promptly.

5. Apache Benchmark effectively generated production-like traffic.

## Improvements

* Implement Horizontal Pod Autoscaler (HPA)
* Add Slack Notifications
* Add PagerDuty Integration
* Implement Multi-AZ Deployments
* Configure Cluster Autoscaler

## SRE Benefits

* Improved visibility
* Faster incident response
* Better reliability
* Reduced downtime
